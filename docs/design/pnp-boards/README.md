# Планшет игрока PnP

Решение пользователя (через PM, 18 октября 2026): стиль C «картонные жетоны», печатный планшет игрока.

Правки пользователя к первому варианту:
- только треки силы 0…+10, шагов 0…+10 через 2, кубиков 1–4;
- окошки «+10 за круг» остаются;
- без Лавки, монет, артефактов, жетона и имени: планшеты разных игроков отличаются только цветом рамки;
- фон — тёплое дерево таверны в свете свечей;
- размер — четверть A4: полоса 210 × 74,25 мм, книжный лист режется тремя горизонтальными линиями.

Версия 4 (18 октября 2026). Пользователь отклонил v3 («слеплено в фотошопе», иконки теряются). Три цельные картинки GPT ([variants/](variants/README.md)) тоже отклонил: «исходный пока лучше всех». Поэтому v4 — доработка исходного:
- клетки лежат в желобках, вырезанных в дереве, а не наклеены на него;
- иконки треков — крупные медальоны 14,6 мм: кремовое лицо, кольцо цвета игрока;
- окошко «+10» за круг — тёмное гнездо под жетон, того же размера, что клетка, на одной линии с треком; без стрелки и подписи;
- в клетках треков числа без «+» (правка пользователя к v4);
- один свет свечи, виньетка и зерно лежат поверх всего планшета, дерево приглушено;
- рамка: цвет игрока и тонкая латунная жилка.

Файлы:
- [board-dog.jpg](board-dog.jpg) — цвет Пса, 210 × 74,25 мм, кадр ~290 dpi.
- [sheet-a4.jpg](sheet-a4.jpg) — превью листа для печати: 4 планшета (Пёс, Кот, Выдра, Альпака) и линии реза.
- `board.html?p=dog|cat|otter|alpaca` — источник, `?sheet=1` — лист A4. Размеры в мм, печать 100 % без масштабирования, клетки 13,5 мм под маркеры 12 мм, поля 3,5 мм по бокам.
- `tavern_wood.jpg` — фон, арт Codex CLI.

## Печать

Пользователь утвердил v4 с правками (18 октября 2026).

- [print-a4.pdf](print-a4.pdf) — лист A4, 4 планшета (Пёс, Кот, Выдра, Альпака), растр 300 dpi. Печатать **100 %, «реальный размер»**, без «вписать в страницу»: тогда клетки 13,5 мм.
- Поля листа: 4 мм сверху и снизу, 4,5 мм по бокам — под непечатное поле принтера. Резать по пунктиру, получится полоса 210 × 72,25 мм.
- PDF собран из кадра, а не печатью Chrome в вектор: в векторе тени клеток режутся на плитки и на печати видны швы.
  Сборка: `python3 tools/probe.py shot --out Logs/probes/board-print --size 2480x3508 --path "/docs/design/pnp-boards/board.html?sheet=1&s=3.125"`,
  затем `sips -s format jpeg -s formatOptions 92 -s dpiWidth 300 -s dpiHeight 300 frame.png --out sheet300.jpg` и `sips -s format pdf sheet300.jpg --out print-a4.pdf`.
