# Планшет игрока PnP

Решение пользователя (через PM, 18 октября 2026): стиль C «картонные жетоны», печатный планшет игрока по образцу экрана игры, A4 на игрока. Сначала один цвет, после «да» — остальные и печатный PDF.

- [board-dog.jpg](board-dog.jpg) — Пёс, A4 альбомный, кадр ~190 dpi.
- `board.html?p=dog|cat|otter|alpaca` — источник. Размеры в мм, печать 100 % без полей.
- `pnp_moment_*.png` — иконки моментов Лавки в стиле C, арт Codex CLI.

Что на планшете:
- треки силы (−3…+10), шагов (0…+10), кубиков (1–6); клетки 13,5 мм под маркеры 12 мм;
- окошки «+10 за круг» у силы и шагов;
- Лавка Джо: пять столбиков по моментам;
- карман монет 1 / 5 / 10 / 50;
- место под артефакты.

Трек силы от −3 и номинал 50 — по данным GD из бот-партий.

Жетоны игроков кота, выдры и альпаки пока экранные, в стиле C их ещё нет.
