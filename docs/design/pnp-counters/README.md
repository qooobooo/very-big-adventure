# Счётчики PnP — концепты

Задача пользователя (через PM, 18 октября 2026): «Нарисуй каунтеры для пнп. Сначала пришли 3 концепта». После выбора направления рисуется весь набор.

## Какие счётчики нужны

По игре 0.1.46. Список ещё сверяется с GD.

| Счётчик | Сколько | Размер для печати |
|---|---|---|
| Монеты 1 / 5 / 10 | запас на всех, номиналы как в кармане планшета | 20 / 22 / 25 мм |
| Маркеры треков: сила (+0…10), шаги (+0…10), кубики (1–6) | по 3 на игрока, в цвете игрока | 12 мм |
| Жетон «+10» за круг трека | по 2 на игрока | 12 мм |
| Маркер ярости монстров (трек 0–8) | 1 | 16 мм |
| Жетоны игроков: пёс, кот, выдра, альпака | по 1, если не фишки-стойки | 30 мм |
| Маркер счётчика дракона (32 деления) | 1 | 16 мм |

## Концепты

Арт — Codex CLI (image generation) по референсам игры. Картинки — `<концепт>_coin10.png`, `_track.png`, `_rage.png`, `_player.png`, 512 px.

| Лист | Идея | Для печати и вырезания |
|---|---|---|
| [concept-a.jpg](concept-a.jpg) | Латунные медальоны, как иконки моментов Лавки | Один набор с экраном игры. Круги вырезать дольше, лучше дырокол-кругорез 12/25 мм |
| [concept-b.jpg](concept-b.jpg) | Дерево с выжженными и подкрашенными знаками | Выглядит как деревянные фишки и тёплый на столе. Круги, тёмный край прощает неровный рез |
| [concept-c.jpg](concept-c.jpg) | Плоские картонные жетоны со светлой каймой | Легче всего печатать и вырезать: кайма прячет неточный рез, маркеры — скруглённые квадраты |

Лист собирается из `sheet.html?c=a|b|c`: верхний ряд в натуральную величину (CSS-мм), нижний ×4.
