# PnP новых карт для тестеров

Задача пользователя (через PM, 19 октября 2026): «Подготовь пнп только новых карт. На этих картах убери моменты с лавок Джо».

| Карта | Колода | Копий |
|---|---|---|
| Застава | Хорошо | 2 |
| Походный горн | Событие, артефакт | 1 |
| Тренировочный манекен | Событие, артефакт | 1 |
| Золотая Подкова | Событие, артефакт (новый текст артефакта) | 1 |

- [pnp-new-cards-a4.pdf](pnp-new-cards-a4.pdf) — лист A4, растр 300 dpi. Печатать **100 %, «реальный размер»**: карта 63 × 88 мм. Резать по меткам на полях.
- [preview.jpg](preview.jpg) — превью листа.
- Формат — как у прежнего PnP карт: 3 × 3 вплотную по центру A4, лицо колоды + название + текст. Отдельной карты артефакта в PnP нет: текст артефакта — на карте события, как раньше.
- Иконок моментов Лавки Джо нет. В игре настройка не менялась.
- Тексты берутся из `src/cards.config.js`. Источник — [sheet.html](sheet.html). Пересборка:
  `python3 tools/probe.py shot --out Logs/probes/pnp-cards-new --size 2480x3508 --path "/docs/design/pnp-cards-new/sheet.html?s=3.125"`,
  затем `sips -s format jpeg -s formatOptions 92 -s dpiWidth 300 -s dpiHeight 300 frame.png --out sheet300.jpg` и `sips -s format pdf sheet300.jpg --out pnp-new-cards-a4.pdf`.
