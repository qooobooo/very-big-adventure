# Доставка задачи

Правила — `AGENTS.md` («Папки, ветки и доставка», «Проверки»), подробности — `docs/development/DELIVERY_PIPELINE.md`. Здесь — порядок шагов.

## Перед доставкой

1. Работа идёт в своей папке `../very-big-adventure-<имя>`, не в основной `very-big-adventure-main` и не в `very-big-adventure` (там `rnd`, не трогать).
   - Своей папки нет — `python3 tools/pipeline.py new <имя>`.
   - Перед работой: `git fetch && git merge --ff-only origin/dev`.
2. Всё закоммичено, `git status` чистый. В конце сообщения коммита — строка соавторства, которую требует твоя среда.
3. Числа баланса — в `src/game.config.js`. Карты — синхронно в `src/cards.config.js` и `cards-google-sheet.csv`.
4. Версию (`src/version.js`) не трогать: её ставит deliver, dev + 1.

## Проба

- **Одна узкая проба на изменённое поведение**, все вместе до ~2 минут: пока они идут, очередь доставок стоит.
  - Логика, правила, сервер: `python3 tools/probe.py test tests/<файл> --out Logs/probes/{run}`.
  - Экран: `python3 tools/probe.py shot --out Logs/probes/{run} [--path "/?…"] [--eval "<js>"]`; пульт — `--path "/controller.html?…" --size 390x844 --mobile`.
- Подходящего теста нет — допиши шаг в существующий файл `tests/`, новый не заводи без нужды.
- Правка с одной пробой, в том числе визуальная, — сразу в deliver. Кадры пользователю — из пробы доставки (`Logs/probes/…`). Не понравилось — следующая доставка. Широкие проверки и варианты на выбор — заранее в своей папке (`deliver --dry-run` или та же `probe.py`).

## Запуск — только в фоне

```sh
python3 tools/pipeline.py deliver --task <slug> \
  --probe "python3 tools/probe.py test tests/<файл> --out Logs/probes/{run}"
```

- Claude Code: `run_in_background`, ждать уведомления. Вывод не опрашивать циклом. Читать итог: блок «Доставлено…» или ошибку.
- В ветке несколько коммитов — добавь `--message "<заголовок>"`.
- Только `tools/`, `docs/`, `tests/`, правила — `--no-app`: без версии, проверки и очереди.
- Мелкие правки одной задачи — одной доставкой.
- Кто сейчас доставляет — `python3 tools/pipeline.py status`.

## Если не прошло

Ничего не залито.

- **Проба упала.** Последние строки уже напечатаны. Если мало — узкий `grep` по логу из `Logs/probes/<run>/`, не чтение целиком. Исправь, закоммить, повтори deliver.
- **Таймаут кадра.** `probe.py` уже повторил один раз. Второй таймаут — разбираться как с регрессией.
- **`node --check` упал.** Синтаксис в названном файле.
- **Конфликт с dev.** `git merge origin/dev`, решить, `git commit`, повторить. В чужом арте и чужих файлах по умолчанию берётся сторона владельца — спроси его.

## После доставки

- **Пользователю**, если задача от него: версия, что сделано, что проверено, один кадр.
  - Сервер :5173 deliver перезапускает сам, если менялся `server.js` и игра не открыта.
  - Если открыта — передай строку из вывода: перезапуск после партии.
- **Чатам — сам.** Блок «Доставлено…» отправь PM и владельцам задетых зон и файлов: чей код и что изменено.
  - Адреса — `python3 tools/pipeline.py chats`, отправка — `SendMessage` по `local_…` id. PM не проси пересылать.
  - Всем — только новые правила, общие инструменты и правки, ломающие чужие пробы.
  - Не больше ~10 сообщений другим чатам подряд без сообщения пользователя.
