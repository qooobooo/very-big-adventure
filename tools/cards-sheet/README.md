# Таблица карт и баланса Cards Config

Google Таблица `Cards Config` с меню «Very Big Adventure»: карты игры по вкладкам колод и числа баланса на вкладке «Баланс», правка текста и чисел, отправка в игру. Задача PM, 12 октября 2026: таблица живёт сама, конфиги руками никто не набирает. Устроено как таблица чисел The Village.

## Как устроено

- **Источник — ветка `dev`.**
  - `src/cards.config.js` — карты, которые читает игра.
  - `cards-google-sheet.csv` — их зеркало. Пишет его `node tools/cards-sheet/cards-csv.mjs`.
  - `src/game.config.js`, `balanceConfig` — числа баланса правил поля (задача PM, 16 октября 2026). Игра читает их как `balance("ключ", эталон)` в `src/game.js`.
  - `balance-google-sheet.csv` — их зеркало с эталонами из `src/game.js`. Пишет тот же `cards-csv.mjs`.
- **Таблица** берёт CSV из `dev`: по «Взять из игры» и сама раз в 5 минут.
- **«Отправить в игру»** — один коммит в `dev`: «Cards from the sheet: …», «Balance from the sheet: …» или «Cards and balance from the sheet: …». Он меняет конфиг и CSV, и только строки изменённых карт и чисел.
- **Скрипт таблицы** — `VbaCards.gs`. В таблицу его заливает `python3 tools/pipeline.py deliver` через `clasp`, когда он поменялся. Вручную — `pipeline.py sheet-push`.

## Настройка, один раз

1. **Script ID.** В таблице Cards Config: Расширения → Apps Script → слева шестерёнка «Настройки проекта» → «Идентификатор скрипта». Скопируй и пришли в чат.
   - Код вставлять не нужно: чат зальёт его сам (`pipeline.py sheet-push --script-id …`).
   - `clasp` работает от входа в Google на этом Mac (`clasp login`, его делает только владелец). Аккаунт должен быть тот, у которого есть доступ к таблице.
2. **Карты.** Обнови страницу таблицы → «Very Big Adventure» → «Взять из игры».
   - Google попросит разрешения скрипту: таблица, внешние запросы (GitHub), запуск по расписанию. Разреши.
   - Старые вкладки не пропадут: станут «good (до синхронизации)» и т. п. В Cards Config их по слову пользователя убрал скрипт (12 октября 2026), они остались в истории версий.
3. **Автообновление.** «Very Big Adventure» → «Включить автообновление».
4. **Отправка в игру** — когда захочешь править карты в таблице. Нужен токен GitHub: github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
   - Repository access → Only select repositories → `qooobooo/very-big-adventure`.
   - Permissions → Repository → Contents: **Read and write**.
   - Срок — на твой выбор. Когда кончится, повтори «Подключить к игре» с новым токеном.
   - «Very Big Adventure» → «Подключить к игре» → вставь токен. Он хранится только в твоём аккаунте Google, другим редакторам таблицы не виден.

## Работа

- **Вкладка на колоду:** good, bad, tadam, event, legendary, shop. Колонки — только те, что у этой колоды есть.
- **Вкладка «Баланс»** — первая. Строка на число: «Что это», «Значение», «Эталон», единица, «Мин» и «Макс», ключ, заметки.
  - Правишь только «Значение» (целое, от «Мин» до «Макс») и «Заметки». Остальное серое: меняется в коде.
  - «Эталон» — число в коде, на нём идут тесты и пробы. Видно, насколько правка ушла от него.
  - Вкладку сделало автообновление само. Без него — «Взять из игры»: оно берёт и карты, и баланс.
- **Цвета.**
  - Серое — id, «Эффект», «Режим»: меняются только в коде. Новые карты и удаление — тоже в коде.
  - Медовое — твоя неотправленная правка.
  - Красное — ошибка. Что не так, скажет «Проверить».
- **Проверки.**
  - Название и текст карты не пустые, без точки в конце.
  - «Копий» — целое от 1.
  - Числа эффекта — целые и только там, где они уже есть: новое число код не прочтёт, стирать нельзя.
  - «Колода» — одна из колод игры, «Когда» — из списка.
  - «Другие числа эффекта» — `ключ=число; ключ=число`. Числа меняй, ключи — только в коде.
- **Отправить в игру** покажет список правок и после «ОК» отправит их.
  - Если ту же ячейку в игре успели поменять, спросит, чьё оставить.
  - Игра на компьютере (:5173) подтянет их за минуту (`pipeline.py follow`, PM), видно после перезагрузки страницы.
- **Автообновление не затирает правки.** С неотправленными правками таблица подтягивает только новые карты, колонки и оформление. Остальное игры придёт после отправки или «Взять из игры».
- **Не трогай** скрытые столбец A, строку 1 и листы `_base`, `_base_balance`: по ним скрипт узнаёт, где какая карта и какое число.
- Без `clasp` (другой компьютер): вставить `VbaCards.gs` в Apps Script целиком и сохранить. Токен сохранится.

## Для чатов

- Поменял карты в `src/cards.config.js`, число в `balanceConfig` или эталон в `balance("ключ", эталон)` — запусти `node tools/cards-sheet/cards-csv.mjs` и закоммить оба CSV вместе с кодом. `deliver` проверяет это сам и не пустит устаревший CSV.
- Новое число баланса: строка в `balanceConfig` (`key`, `value`, `name`, `unit`, `min`, `max`) и вызов `balance("ключ", эталон)` в коде; ключи сверяет `tests/balance-config.test.cjs`. В таблице строка появится сама.
- Руками в CSV — только `notes`: заметки живут лишь в CSV и в таблице. Так же у баланса.
- Колонки CSV и поля конфига:

  | CSV | `src/cards.config.js` |
  |---|---|
  | `title`, `shortTitle`, `count`, `description`, `artifact_desr`, `moment` | поля карты |
  | `effect_type` | `effect.type` |
  | `amount`, `steps`, `cost`, `dice`, `mode` | те же ключи `effect` |
  | `target_deck` | `effect.deck` |
  | `effect_extra` | остальные ключи `effect`: `ключ=число; ключ=число` |
  | `notes` | нет, только CSV и таблица |

- Перенос строки в тексте карты в CSV — `\n`.
- Колонки CSV баланса: `key,name,value,default,unit,min,max,notes`. `default` — эталон из `src/game.js`, `notes` — только CSV и таблица, остальное — из `balanceConfig`.
- Тест: `tests/cards-sheet.test.cjs`. Он гоняет чистую часть `VbaCards.gs` в node: CSV из конфигов, правку из таблицы, проверки ячеек. Вкладку «Баланс» — на макете таблицы.
